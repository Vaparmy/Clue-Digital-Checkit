# Case Notebook

Detective notebook and solver for mystery deduction board games. Works on phone, tablet and PC, installs to the home screen, and works offline.

## Put it online with GitHub Pages
1. Sign in at github.com and click **New repository**. Name it `case-notebook`, set it to **Public**, and create it.
2. Click **uploading an existing file**, drag in everything from this folder (all 9 files), and click **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**, then **Save**.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/case-notebook/`.

## Install it like an app
- **Android (Chrome):** open the site, tap the ⋮ menu, then **Install app** or **Add to Home screen**.
- **iPhone (Safari):** open the site, tap **Share**, then **Add to Home Screen**.
- **PC (Chrome or Edge):** click the install icon at the right end of the address bar.

## Updating
Replace `index.html` with the new version. Then open `sw.js` and change `case-notebook-v1` to `case-notebook-v2` (and so on) so installed copies pick up the update.
